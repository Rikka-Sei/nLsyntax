# 约束表迭代记录

## v0.1 首版（88 条）
- 四类：职场黑话、英译隐喻、体感隐喻、英文隐喻，外加 3 条伴随句式（限次数，不禁用）。
- 每条规则带"字面语境排除词"，避免误伤落地窗、右对齐、Unix 管道、承重墙（装修）等字面用法。

## 第 1 轮测试
- 样例：`tests/bad.txt`（16 行模型腔）、`tests/clean.txt`（28 行正常中文，含大量字面用法）。
- 结果：clean 0 误报；bad 漏报 3 处。
- 原因与修复：
  - "它落在哪些模块上"：规则要求特定主语，放宽为"落在 + 哪些/哪里"也命中。
  - "很有温度"：排除词里写了"度"，而"温度"本身包含"度"，规则永远不触发。删除该排除词，并在维护说明里加上"排除词不能是被检词的一部分"。
  - "论证还需要再拧紧"：规则要求"论证拧紧"相邻，改为单独匹配"拧紧"，用螺丝、瓶盖、阀门等排除字面用法。

## 第 2 轮测试
- 新样例：`tests/bad2.txt`（15 行），`tests/clean2.txt`（17 行字面用法）。
- 首次运行：bad2 全部漏报，暴露出两类空白：
  - 工具/方位类英文直译：透镜（lens）、钥匙在于（key to）、画地图（map）、指南针（compass）、工具箱（toolbox）、增长引擎/燃料、支点（fulcrum）、自然长出来（grow organically）、能力的地板（floor）、尺子衡量（yardstick）、收敛（converge）。
  - 心理咨询腔：被看见、我看见你、抱持、情绪容器。新增"咨询腔"类别。
  - 另补：拉通、各方有感知、第一性原理。
- 决定不收录："走钢丝"。它是中文母语者日常会说的比喻，符合人类分布。已移入 clean2 作为防止过度纠正的样例。
- 修复后：bad 与 bad2 全部命中；clean 与 clean2（共 45 行）0 误报。规则总数 106 条（禁用 62、慎用 44）。

## 后续可扩展方向
- 收集真实对话中的模型输出，按判定标准三问人工标注，再补规则。
- "慎用"级目前只提示，可以针对特定读者（如非技术用户）把部分慎用升级为禁用，做成配置项。

## v0.2 实验驱动的修订（128 条）
详见 `experiment.md`。
- 结构保持"三问原则 + 词表"。实验中，只给原则的版本在较弱模型上会漏词；多遍审查和强制跑脚本都没有带来可测收益。
- 从两轮无 skill 输出中，收入 22 条评审标出的新说法，例如承压、盘子 / 基本盘、跑通、触点、显性化、漏水的桶、补最痛的功能、回血、让对方防御、clean seams。这些规则标记为 `"source": "实验挖掘"`。新增 `tests/bad3.txt` 和 `tests/clean3.txt`。
- 修复：原规则只认"被看见"，不认"被看到"。
- 修复：改写提示里藏着的黑话，如"保底方案""切入角度""打通信息""先突破"，改为直白说法。
- 新增"处理用户给的文本"一节，分"只标注"和"改写"两种模式，改写再分两档改动幅度。"只标注"不给替换写法；"句内清理"要求选长度相近、语法通顺的说法，不原样贴词表里的描述。这两条是实验中发现问题后改的，并复测过。
- 检查脚本改为只在长文和改写用户文本时使用，不再要求每次回复都运行。
- 新增 `tests/heldout.json`，48 条留出评测词，不并入规则。
